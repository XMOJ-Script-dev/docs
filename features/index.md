# 功能总览

所有功能都在「插件设置」里开关：登录后点右上角的用户菜单，选「插件设置」。下面按设置页的顺序列出。

## 讨论和社区

| 功能 | 说明 |
|------|------|
| 恢复讨论与短消息 | 恢复小明的OJ上关掉的讨论区和短消息，由 XMOJ-Script 的服务器提供。 |
| 讨论提醒、短消息提醒 | 有人回复、@你或者发短消息时弹出提醒。 |
| [粘贴发图](./image-hosting) | 在讨论区和短消息里直接粘贴截图。 |
| [用户评分](./rating) | 按 AC 率显示分数和彩色用户名。 |
| [徽章](../community/badges) | 用户名旁边的小标签。 |
| 设置云同步 | 把插件设置同步到云端，换电脑不用重新设置。 |

## 做题和提交

| 功能 | 说明 |
|------|------|
| 查看更多标程 | 能看到更多题目的标准程序。 |
| [获取测试点数据](./get-data) | 提交没过时，拿到出错测试点的输入。 |
| 提交前检查代码 | 检查是否用了文件输入输出、是否有编译错误。 |
| 自动选择 O2 优化 | 提交时默认勾选 O2。 |
| 自动识别验证码 | 在本地识别提交页的验证码，没把握时留空，让你自己填。 |
| 复制测试样例 | 修复题目页样例有时复制不了的问题。 |
| 复制题目或题解 | 把题目或题解复制成 Markdown。 |
| 比较代码 | 对比两次提交的代码。 |
| 导出 AC 代码 | 把自己 AC 过的代码导出，每道题一个文件。 |
| 状态页自动刷新 | 提交后评测结果自动刷新。 |

## 比赛

| 功能 | 说明 |
|------|------|
| 自动刷新 | 比赛列表和排名自动刷新。 |
| 倒计时 | 比赛列表等页面上的时间自动倒数。 |
| 题目切换器 | 比赛题目页左侧的题目列表，方便切换。 |
| 一键打开所有题目 | 在新标签页里打开比赛的全部题目。 |
| [自动提交当年代码](./auto-handin) | 把自己以前 AC 过的代码提交到当前比赛。用之前务必看说明。 |
| 提高 AC 率 | 自动重新提交已 AC 的题目，用来提高 AC 率。 |
| 回放视频下载 | 回放页面多一个下载按钮。 |

## 界面

| 功能 | 说明 |
|------|------|
| 新的顶部导航栏 | |
| 新版 Bootstrap 样式 | 建议保持开启。 |
| 重新排版 | 建议保持开启。 |
| 界面主题 | 亮色、暗色或跟随系统。 |
| 极简黑白界面 | 黑白配色、衬线字体，也就是这份文档的样子。 |
| 彩色文字、动画 | |
| 状态图标 | 题目前的状态提示换成图标。 |
| 内存和耗时加单位 | 状态页的内存和耗时显示单位。 |
| 翻译 | 翻译部分英文，统一用语。建议保持开启。 |
| 链接换成按钮 | 把方括号包着的链接换成按钮。 |
| 去掉多余提示 | 去掉反复弹出的提示。 |
| 删去无法使用的功能 | 建议保持开启。 |
| 图片放大 | 点图片可以放大看。 |

## 账号和其他

| 功能 | 说明 |
|------|------|
| 自动跳转登录 | 打开需要登录的页面时，自动跳到登录页。 |
| 保存用户名和密码 | 下次登录自动填好。 |
| 修复登录后跳转失败 | 建议保持开启。 |
| 下载页面增强 | 下载页多一些内容。 |

设置页还有两个「仅供开发者使用」的调试选项，平时不要打开。
