# 自动提交当年代码

在比赛里，把你自己以前 AC 过的代码一次性提交到这场比赛。

::: danger 用之前先看这里
- **一眼就能看出来。** 交上去的代码和你以前的提交一模一样，而且每道题只隔一秒左右。看提交记录或排名的人都能看出这是批量提交的。
- **没有停止按钮。** 想停下只能离开这个页面，正在交的那道题还是会交上去。
- **不保证通过。** 题目的数据、时限或内存限制可能改过，以前 AC 的代码现在不一定还能过。

XMOJ-Script 不对提交结果负责。
:::

## 它做了什么

对比赛里你还没 AC 的每一道题，脚本会找你自己在这道题上最近一次 AC 的代码，原样提交到这场比赛（C++，开 O2）。只会用你自己的代码；以前没 AC 过的题会跳过。

每道题之间会等一秒。某一道交失败了（比如需要填验证码），就会停下，并在按钮上显示原因。

## 怎么用

1. 在「插件设置」里确认「自动提交当年代码」是开着的。
2. 打开比赛的题目页。
3. 点工具栏上的「自动提交当年代码」。
4. 等它跑完，然后逐题看一下评测结果。

## 常见问题

**没看到按钮？** 确认打开的是比赛的题目页，并且设置已经保存，然后刷新页面。

**交到一半停了？** 看按钮上的提示。需要验证码的话，去提交页面手动交一次，再回来点按钮，已经 AC 的题会被跳过。
