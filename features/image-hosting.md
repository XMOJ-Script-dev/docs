# 粘贴发图

在讨论区发帖、回复或者写短消息时，可以直接粘贴图片。

## 怎么用

1. 截图，或者在网页上右键「复制图片」。
2. 在输入框里按 <kbd>Ctrl</kbd>+<kbd>V</kbd>（macOS 上是 <kbd>⌘</kbd>+<kbd>V</kbd>）。
3. 等上传完成，输入框里会出现一行 `![](https://assets.xmoj-script.uk/GetImage?ImageID=…)`。
4. 正常发送就行。

PNG、JPG、GIF、WebP 都可以。粘贴的必须是图片本身，复制文件或文件路径是不行的。

## 发图之前

::: danger 任何拿到链接的人都能看到图片
图片不需要登录就能打开，你自己也删不掉，要删除只能[联系我们](https://www.xmoj-script.uk/privacy.html)。所以不要上传带真实姓名、学校、联系方式或人脸的图片。
:::

- 不要发违规内容，见[使用条款](https://www.xmoj-script.uk/terms.html)。
- 管理员可以不经通知删除违规图片，多次违规会被禁止上传。
- 服务器在国外，上传和加载可能比较慢。

## 上传失败

| 现象 | 处理 |
|------|------|
| 粘贴后没反应 | 重新复制图片本身，而不是文件。 |
| 一直在上传 | 检查网络，关掉代理再试。 |
| 提示服务器错误 | 等几分钟再试；一直不行就到 [GitHub Issues](https://github.com/XMOJ-Script-dev/XMOJ-Script/issues) 反馈。 |
